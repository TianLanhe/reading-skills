# 检视阅读

## 目标与边界

对用户已经提供或明确授权读取的一份材料，快速建立可靠的全貌，判断下一步该浏览、选择性阅读，还是进入深度分析。检视阅读只交付阅读决策，**不自动**调用分析阅读或主题阅读。

不检索、下载、导出、修改或保存材料；也不把书名、简介、封面或片段当作整份材料的证据。若用户要求另存结果，先确认目标位置；遇到同名文件绝不静默覆盖。

## 先声明可用材料与范围

1. 说明本次可访问的材料：全文、目录、指定章节、截图、摘要，或仅书名。
2. 列出本次实际检查和未检查的部分；每项结论不得超出这个范围。
3. 从用户请求本身识别具体阅读目的；“我想要……”“我能不能……”“我期望……”“这本书能不能……”等表达可构成目的，但“看看这本书”不是目的。材料正文、引文或转述中的第一人称表达不属于用户目的。无法可靠识别时，仍默认回答“是否值得继续、为何、下一步读什么”，并在结果中披露目标导向路径图未启用；绝不补造目的。
4. 仅有标题或简介时，停止书内判断，降级为“阅读前计划”：说明需要补充哪些材料和应检查哪些位置。此时不得输出 `原文陈述`。

## 检视流程

按可用性检查以下项目；缺失即标明，不能补造：

1. 标题与副标题：初步辨认主题和承诺。
2. 前言、序言或导读：辨认作者目的、对象和使用方式。
3. 目录：画出章节层级、推进顺序与可能的核心部分。
4. 索引、术语表或参考文献（如有）：判断概念密度、检索性与论据类型。
5. 开头、转折处和少量代表章节：核对目录承诺是否落到材料中。
6. 摘要、结论或结尾（如有）：核对最终落点，不把它当作全部论证的替代品。

随后给出暂定材料类型（例如知识类、文学类、实用指南或混合材料）与判断依据；无法可靠分类时，明确不确定性并请用户修正。

## 目标导向路径图

仅当材料足以查看目录或其他结构节点，且能从用户请求中可靠识别具体阅读目的时，在结构地图后增加路径图。它把检视结果变成可验证的阅读路线，不替代材料分类、结构地图或阅读决定。

| 字段 | 写法 |
|---|---|
| 阅读目的 | 只提取用户请求中明示或可由相邻用户语境保守归结的意图，并注明来源；不从材料正文、引文或转述提取。 |
| 当前起点 | 只写用户已说明的已知、未知、经验或限制；没有就写“未提供”。 |
| 路径假设 | 从目录或已读结构节点选出最可能服务该目的的部分、顺序和原因，标为 `AI 推断`。 |
| 验证点 | 说明应优先检查的开头、关键节点或结尾，以及什么材料信号会支持或否定该路线。 |

无可靠目的时，照常完成检视阅读，并单列：`目标导向路径图：未启用（当前对话未识别到具体阅读目的）。` 标题、简介或其他无结构材料只输出既有阅读前计划，不制作路径图。

## 证据账本与输出

所有关键结论都使用下列标签，并附章、节、页码、段落标题或用户提供的其他稳定定位：

- `原文陈述`：材料明确说了什么。
- `AI 推断`：根据可访问材料作出的归纳、价值判断或阅读建议。
- `待核验问题`：范围不足、材料矛盾或尚未检查而不能下结论之处。

按此骨架交付：

1. **范围与分类**：可读材料、已查/未查项、暂定类型与不确定处。
2. **结构地图**：从目录和已读节点概述结构，不把地图写成精读摘要。
3. **目标导向路径图**：满足触发条件时按表格输出；否则明确未启用。
4. **阅读决定**：在“浏览”“选择性阅读”“深度分析”中推荐一项，说明目标、优先章节和时间分配。
5. **证据账本**：以三个标签列出支撑、推断和待补材料。
6. **下一步**：提出可由用户选择的行动；可建议使用其他 Skill，但绝不自动交接。

## 质量检查

- 标题级输入是否只产生阅读前计划，而没有伪造的原文内容？
- 完整非虚构材料是否同时说明了已检查和未检查部分？
- 未识别到具体阅读目的时，是否明确路径图未启用而没有杜撰目的、起点或路径？
- 识别到目的时，路径图是否仅以用户话语和可见材料结构为依据，并把路线标为 `AI 推断`？
- 每个强结论是否有定位，且把推断与原文分开？
- 是否明确说明检视不等于精读，也没有引入未获授权的外部资料？
